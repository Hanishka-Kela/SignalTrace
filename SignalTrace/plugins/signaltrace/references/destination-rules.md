# Citation and source decision rules

Read this reference for destination tracing or external source verification.

For each observed citation preserve: nearby claim text, anchor text, authored URL, redirect hops, final URL, response state, and the entity/task the final representation actually supports. A canonical difference is not a variant failure unless resolved evidence conflicts. A documented rename or successor is not broken. Assign responsibility as `site-published link`, `external publisher`, `assistant-generated citation`, or `unresolved`; never assign an invented URL to the audited site.

Only call a destination wrong when the cached final page positively supports a different entity, version, variant, region, configuration, or task. Missing context is ambiguous. A homepage destination is a finding only when an attached specific claim cannot be supported there and a site-published citation caused the loss.

External verification is targeted: fetch only input-supplied evidence sources. Compare the same entity and predicate with all scope qualifiers intact. Independence requires distinct origin and no observed canonical/feed-copy relationship. Two copies support only two-source agreement, not web-wide agreement. Restricted, placeholder, locked, or image-only evidence cannot corroborate a claim. No suitable source means `not assessed`.
